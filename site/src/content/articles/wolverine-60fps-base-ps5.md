Insomniac has confirmed that **Marvel's Wolverine** will offer 60 frames per second **with ray tracing** as its default performance mode — and, notably, that mode isn't reserved for the PS5 Pro. It runs on the **base PlayStation 5** too, which the studio is calling a first for its games.

## Why this matters

For a character defined by speed and brutality, a locked, high-framerate presentation isn't a nice-to-have — it's core to how the combat is meant to feel. Wolverine's whole appeal is momentum: lunges, slashes, and berserker flurries that only land when the game stays fluid. A 60fps-with-ray-tracing default means players on standard hardware get the version the developers clearly consider definitive, rather than being pushed toward a Pro upgrade to see it at its best.

It also signals confidence. Shipping ray tracing *and* 60fps as the baseline on the base console is a real engineering flex, and it suggests Insomniac's tech has come a long way since the first Spider-Man.

## The bottom line

If it holds up in the final build, this is exactly the kind of "no compromises" standard fans have been asking for. We'll be watching closely as more hands-on previews land.
